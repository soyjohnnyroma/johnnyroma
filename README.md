# johnny roma — portafolio digital

Sitio estático de una sola página, preparado para GitHub + Cloudflare Pages.

## Archivos
- `index.html`, `styles.css`, `script.js`: sitio y comportamiento.
- `assets/`: isotipo, retrato e imágenes optimizadas de proyectos.
- `manifest.webmanifest`, `sw.js`: instalación como PWA y caché básica para uso sin conexión.
- `_headers`: encabezados de seguridad y tipos de contenido para Cloudflare Pages.

## Publicación
Sube el contenido completo de esta carpeta al repositorio conectado a Cloudflare Pages. No requiere backend ni variables de entorno.

## Instalación
Después de publicar bajo HTTPS, abre el sitio en Chrome o Edge y usa “Instalar aplicación” o “Añadir a pantalla de inicio”. La disponibilidad exacta depende del navegador y del dispositivo. No es un APK ni una publicación en Play Store.

## Notas
- El reloj muestra la hora de Colombia (`America/Bogota`) sin segundos.
- Los enlaces de proyectos apuntan a las direcciones proporcionadas por el propietario.
- Maison Muebles se identifica como prototipo con datos de demostración.
- Las imágenes de proyecto son capturas proporcionadas para el portafolio.
